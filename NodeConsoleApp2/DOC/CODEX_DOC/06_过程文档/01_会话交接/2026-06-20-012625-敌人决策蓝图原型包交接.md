## 已确认的设计边界

1. 以 `enemy_decision_state_machine_v1` 口径表达，不再延续旧“意图循环 / 行为决策”。
2. 全屏编辑器是核心工作台，不是附属弹层。
3. 左侧必须有决策模板、节点库和敌人技能库。
4. 画布必须表达真实端口：`flow / true / false / fallback / nextState`。
5. 右侧必须能编辑选中节点属性。
6. 底部必须提供路径预览、模拟上下文和校验问题。
7. 路径预览只解释状态机求值路径，不承担战斗平衡模拟。
