# 评审意见响应

本版来自 v1 原型评审意见。

## 用户反馈

用户认为 v1 效果“稍微好一点”，基本满意，但指出状态机图和一般蓝图逻辑图不同：

1. 状态机图有更多循环。
2. 状态机会经常从后段指向前面。
3. 状态机会包含连续判断。
4. 需要针对状态机走势进一步优化。

## 处理结论

反馈成立，需要新版本原型处理。因为这不是轻微文字修正，而是关键布局和图谱读法变化，所以按原型包规范创建 v2，不覆盖 v1。

## v2 具体变化

### 1. 从普通蓝图图谱改为状态机轨道图

处理方式：

1. 上层为状态轨道。
2. 中层为判断轨道。
3. 下层为动作轨道。
4. 底部为回流轨道。

目的：让作者先读“能停在哪些状态”，再读“本回合检查什么”，最后读“动作结束后回到哪里”。

### 2. 将回流线外置

处理方式：

1. 所有 Action.nextState 使用底部外侧回流轨道表达。
2. 回流线使用不同颜色和更粗线条。
3. 回流分析态单独高亮回流线，并在右侧列出每个 Action 的回流目标。

目的：避免后段回指前段的线穿过判断节点，和本回合 flow 混在一起。

### 3. 保留路径预览，但强化 nextState

处理方式：

路径态显示：

```text
默认状态 -> HP <= 35%: true -> 恢复状态 -> 使用复苏药剂 -> 回流默认状态
```

目的：让路径预览不仅回答“做了什么动作”，也回答“动作后进入哪个状态”。

### 4. 增加状态机导航

处理方式：

左侧增加“主循环 / 恢复支路 / 二阶段支路”的导航卡片。

目的：敌人决策图变复杂后，作者可以按行为走势浏览，而不是只按节点列表浏览。

## 未处理内容

1. 本版仍是静态原型，没有实现真实拖拽。
2. 本版没有接入 evaluator。
3. 本版没有替换运行页。
4. 本版没有处理移动端降级。

这些内容应进入后续运行页实现和验收，而不是在原型中伪装完成。
