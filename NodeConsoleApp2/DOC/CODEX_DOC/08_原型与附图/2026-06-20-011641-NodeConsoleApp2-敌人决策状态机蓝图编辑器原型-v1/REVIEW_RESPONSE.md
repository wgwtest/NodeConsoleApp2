# 评审意见响应

本版来自对当前敌人决策全屏面板的评审意见处理。

## 已处理意见

### 1. 旧画布只有几个抽象框

处理结果：成立。

本版改为具体敌人样例“腐锈投石兵”，并放入完整状态机链路：

```text
入口 -> 默认压制状态 -> HP 判断 -> 恢复状态 -> 使用复苏药剂 -> 默认压制状态
默认压制状态 -> HP 判断 false -> 锈刃割裂可用？ -> 锈刃割裂 / 投石
```

### 2. 旧连线不像蓝图，只是勉强能连

处理结果：成立。

本版明确显示端口语义：

1. `flow`
2. `true`
3. `false`
4. `fallback`
5. `nextState`

实现阶段不能退回单一“连出”按钮。

### 3. 模板、技能库和属性编辑缺乏真实业务意义

处理结果：成立。

本版左侧放入决策模板、节点库、敌人技能库；右侧放入条件编辑、技能槽位绑定、端口规则；底部放入模拟上下文、路径轨迹和校验问题。

### 4. 路径预览不能变成战斗平衡模拟器

处理结果：成立。

本版路径预览只解释状态机访问路径、条件结果、选中 Action 和 nextState，不计算伤害胜负，也不承担敌人平衡模拟。

## 未处理或留待实现

1. 本版没有实现真实拖拽、连线和保存。
2. 本版没有接入真实 evaluator。
3. 本版没有接入 runtime pack 发布校验。
4. 本版没有替换当前运行页。

这些内容应进入后续实现计划，而不是继续在原型中伪装完成。
