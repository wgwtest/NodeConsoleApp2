# S9 动画资产管理设计说明

最后整理时间：2026-06-06

状态：`规划中 / 独立子系统`

## 1. 子系统范围

本子系统负责动画资产的导入、构建、登记、查询、审计、预览、发布和运行时解析边界。

它管理的是跨角色、跨敌人、跨技能和跨主流程的动画资产，不属于单个战斗页面、敌人编辑器或角色配置文件。

## 3. 归属规则

1. 动画集、clip、运行时图集、manifest、构建状态、引用关系和预览能力归入本子系统。
2. 战斗运行时只消费本子系统发布的 `animationSetRef` 和 clip，不直接管理动画资产。
3. 敌人编辑器、角色编辑器、技能编辑器只引用动画集或动画 key，不直接维护 sheet 路径、帧宽、帧数和构建参数。
4. Spine 专项生产链路仍保留在 `S8_UI与交互基线` 的既有文档中；本子系统优先服务帧序列 / spritesheet 动画资产。
